# Gerar o APK pelo GitHub Actions

O workflow `.github/workflows/build-apk.yml` compila um APK debug automaticamente a cada push na branch `main` e também pode ser executado manualmente.

Depois da execução, o APK fica no artefato **Treino-Hibrido-APK**.
